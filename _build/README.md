# 建置管線

從上游 `pf1e_compendium_chn` 的簡體對照表重新產生 `translations/`。
只有上游更新時才需要跑；平常維護模組本身用不到。

```powershell
_build\build.bat        # 建置 + 驗證，驗證沒過回傳非零
```

在含中文的路徑下要用絕對路徑呼叫 `build.bat`，相對路徑 cmd 會找不到檔案。

## ⚠ 現行 `translations/` 有 1,529 條未轉換的簡體

**已發布的譯文並非由本管線產生**，裡面還残留大段未轉換的簡體中文：

| 檔案 | 未轉換字串 |
|---|---|
| `pf1.class-abilities.json` | 656 |
| `pf-content.pf-feats.json` | 436 |
| `pf1.spells.json` | 288 |
| `pf1.feats.json` | 109 |
| 其餘四檔 | 40 |
| **合計** | **1,529 / 49,617** |

集中在「戰策增益」（Pathfinder Unchained）那一段：
`战策增益` `消耗2点耐力` `战策资源出处` 等。

**跑一次 `build.bat` 就會全部修掉**（驗證由 FAIL 轉 PASS）。
本管線能正確處理這些字串，只是現行內容從來沒用它重建過。

問題是重建會**連帶套用下一節那些未定案的術語替換**：

- 修掉未轉換的簡體：1,530 條（無爭議，應該修）
- 術語替換：551 條（**未定案**，見下節）

兩者在同一次建置裡分不開。要只修簡繁不改術語，
得先把 `TERM_MAP` 清空或把争議項拿掉再跑。

## ⚠ 目前的產出與 `translations/` 內容不一致

**直接跑會覆蓋掉 30 個檔案，其中 16 個內容真的會變。** 已知差異來自術語表：

| 上游／現行 | 本管線會轉成 |
|---|---|
| 範本 | 模板 |
| 設定陷阱 | 設置陷阱 |

`pf-content.pf-feats.json` 一個檔就有 507 條字串受影響。

原因是本管線會套用介面層 `pf1-zhtw` 的 `TERM_MAP`，而現行 `translations/`
是在沒有那層術語統一的情況下產生的。**哪一版譯名才對還沒定案**，
所以先保留現行內容，沒有用管線的產出覆蓋。

要採用管線版譯名之前，先確認這兩組詞（以及其他 `TERM_MAP` 項目）在
PF1 語境下的正確譯法，必要時查 `4_工具與筆記\pf1-glossary`。

## 術語表的正本

`TERM_MAP` 與 `PROTECTED` 從介面層 import，不在這裡複製一份：

```
D:\TRPG\4_工具與筆記\pf1-zhtw\_build\build_zhtw.py
```

改譯名只改那一份，兩層才會一致。合集層另有 `EXTRA_TERMS`／`EXTRA_PROTECTED`
放規則書內文才出現的詞，寫在 `build_compendium.py` 開頭。

## 驗證項目

`verify_compendium.py` 檢查七項，任一不過回傳非零：

1. 檔案集合一致（30 檔）
2. `entries` 鍵集合一致（Babele 靠英文鍵比對）
3. `mapping` 完全未變（欄位路徑被轉換 Babele 會壞）
4. 結構一致
5. HTML 標籤完好
6. `@` 連結的文件 ID 完好
7. 無殘留簡體（OpenCC 反向轉換偵測）

改 mapping 值、刪 entries 鍵、注入簡體、改連結 ID 這四種破壞都實測會被抓到。

## 轉換時的三個坑

**一、`{...}` 在介面層與合集層意義相反。** 介面層的大括號是 Foundry 插值變數
要保護；合集層的大括號幾乎都是中文——3,119 個 `@Compendium[...]{中文名}`
顯示標籤，加上 180 個 `{2+智力修正}` 算式。沿用介面層的 `PLACEHOLDER`
會把這 3,299 處全留在簡體。真正不可動的只有方括號裡的文件 ID。

**二、`<[^>]+>` 抓標籤太貪心。** 來源有 21 處長得像標籤但不是：
`<水晶球 (crystal ball)>` 這種拿角括號當引號的物品名（18 處），
和 `<p被壓制的生物…` 漏打 `>` 的破損標籤（3 處）。
寬鬆比對會把後面的中文一起當標籤保護。改成限定 `</?標籤名 …>` 的形狀。

**三、反向偵測殘簡會誤報。** OpenCC 一對多映射會想把已經正確的繁體再改一次：
斗轉星移→鬥、無厘頭→釐、風采→採、趨吉避凶→兇。驗證改成逐字比對並跳過
`AMBIGUOUS` 那組，另外排除網址與標籤內部的文字（`#TOC-黑暗视觉` 是
d20pfsrd 錨點，轉了連結失效）。
